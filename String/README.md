# String Operations in C

## Description
This program implements basic string operations in C without using the built-in functions from the `<string.h>` library. It demonstrates how strings can be manipulated using character arrays, loops, and user-defined functions.

## Features

The program includes the following operations:

1. **Length()**
   - Finds the length of a string.
   - Works similar to `strlen()`.

2. **Display()**
   - Displays the string.

3. **Copy()**
   - Copies one string into another.
   - Works similar to `strcpy()`.

4. **Concatenate()**
   - Joins two strings together.
   - Works similar to `strcat()`.

5. **Compare()**
   - Compares two strings and checks whether they are equal.
   - Works similar to `strcmp()`.

6. **Reverse()**
   - Reverses the characters of a string.

7. **ToUpper()**
   - Converts lowercase letters into uppercase.

8. **ToLower()**
   - Converts uppercase letters into lowercase.

9. **IsPalindrome()**
   - Checks whether a string is a palindrome.
